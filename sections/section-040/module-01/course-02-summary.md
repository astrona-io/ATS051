# Summary

An actionable alert connects observed impact to an owner and a useful response. Symptoms often provide stable notification conditions, while cause metrics add diagnostic context.

Error-budget burn describes how quickly unacceptable outcomes consume the allowed budget, with windows chosen for timely and sustained evidence. Low traffic, planned maintenance and monitoring-path failures need explicit treatment so a quiet or noisy system is not mistaken for trustworthy health.
