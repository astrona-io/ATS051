# Dashboarding basics

This section covers dashboarding basics. It develops dashboards That Explain Population, Units And Gaps through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Choose panels for rate, duration, errors and saturation.
- Explain time range, resolution and units.
- Preserve grouping and denominator context.
- Distinguish display gaps from measured zero and alert evaluation.
