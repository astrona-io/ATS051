# Understand and Use Alertmanager

This section covers understand and Use Alertmanager. It develops routing, Grouping, Silences And Inhibition through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Trace alerts through the Alertmanager routing tree.
- Distinguish grouping timers from rule persistence.
- Compare silencing and inhibition without changing source conditions.
- Explain receiver delivery and high-availability deduplication limits.
